# clinicianmicrogrants.org

Website for the Clinician Microgrant Fund, served free by GitHub Pages.

- `index.html` is the home page; `med-shed-kit/index.html` is the Med Shed Kit page.
- `assets/style.css` holds the shared design; `assets/forms.js` shows the thank-you notes.
- `CNAME` tells GitHub Pages to serve the site at clinicianmicrogrants.org.
- The forms send to MailerLite (groups "CMF - Founding board interest", "CMF - Updates" and "Med Shed Kit - Interest").

This repository is public. Never put patient information, passwords, or private notes in it.
